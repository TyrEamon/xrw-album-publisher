Let the phone pick a folder, and build the uploader for android

The two buttons that only worked on Windows now have phone paths: the page calls
into the shell, which opens the system folder picker (copying a folder the app
cannot read into app storage) and, for the snapshot button, reports what is
inside instead of asking for a file manager that cannot open a private
directory.

The CI also builds with GOOS=android now. Only that build tag loads the Android
trust store, so the linux build of the same code could not verify a single HTTPS
certificate on the phone.
